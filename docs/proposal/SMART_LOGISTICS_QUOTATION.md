## 6. 포함 / 미포함

### 포함

- 기존 ANH WMS 코드베이스 기준 분석, 설계, 구현, 스테이징 배포
- 착수·중간·완료 보고, 주간 진행 보고
- 화면정의서, API 명세, 운영 런북, 역할별 매뉴얼
- 핵심 경로 자동 시험 및 인수 시험 지원
- 표준안: 설비 1종 소프트웨어 어댑터, 시뮬레이터 또는 실장비 연동 시험
- 오픈 후 2주 안정화 (표준·풀), 기본안은 1주

### 미포함

- DAS/DPS, 소터, 컨베이어, AMR 등 **하드웨어 구매·설치·이전**
- 전기, 랙, 네트워크 공사, 현장 안전 인증
- 쇼핑몰·택배사 월 이용료, 운임, 라벨 용지
- 운영 OpenAI/LLM 토큰 비용 (파일럿 한도 초과분)
- 신규 판매채널 전용 커넥터 (쿠팡·네이버 등 신규 개발은 별도)
- 발주처 외 제3자 창고 다중 테넌트 재구축
- 오픈 후 상주 유지보수 (별도 유지보수 계약)

유지보수는 오픈 다음 달부터 공급가액의 월 1.2%를 권고한다. 표준안 기준 월 2,064,000원 (부가세 별도).

## 8. 패키지 선택 기준

| 상황 | 권장 |
|------|------|
| 올해 입고·주문·재고 정합성만 맞추면 됨 | 기본안 |
| 내년 자동화 라인 1개를 파일럿하고 싶음 | 표준안 |
| 설비 3종 이상 발주가 이미 확정됨 | 풀패키지 |
| 하드웨어 발주가 미정 | 기본안 착수 + 트랙 C는 인터페이스만 선설계 |

트랙 C만 나중에 붙일 경우, 표준안 트랙 C 공급가 58,760,000원 + 재착수 20%를 별도 견적한다.

## 9. 전제와 제외 책임

1. 견적 유효기간은 60일이다. 환율·노임단가·설비사 스펙 변경 시 재산정한다.
2. 설비 프로토콜이 착수 후 4주 안에 제공되지 않으면 트랙 C 일정은 자동 순연한다. 인건비는 대기 일수만큼 정산하거나 시뮬레이터 범위로 축소한다.
3. 운영 DB 마이그레이션 창은 발주처가 보장한다. 창 지연으로 생긴 대기는 별도 정산한다.
4. 본 견적 금액은 소프트웨어 구축비이며, 정부 지원사업 신청 시 하드웨어·부가세 처리 기준은 해당 사업 지침을 따른다.
