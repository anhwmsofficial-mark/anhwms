# 스마트스토어 모바일 상세 운영

아하득템 스토어의 상세 이미지를 모바일에서 보이는 JPG HTML로 바꾼 뒤, 담당자 승인을 받아 네이버 커머스 API의 `detailContent`만 교체합니다.

적용한 상품은 스마트스토어 판매자센터의 SmartEditor ONE 문서가 아니라 HTML 상세로 전환됩니다. 공식 API는 SmartEditor ONE 문서를 작성하거나 되돌리지 못합니다. 반영 전에 테스트 상품을 확인하고, 필요하면 적용 전 HTML을 작업 이력에서 복사해 판매자센터에 수동으로 되돌립니다.

## API 발급

1. [커머스 API 센터](https://apicenter.commerce.naver.com/)에서 아하득템 애플리케이션을 등록합니다.
2. 상품 조회와 채널 상품 수정 권한을 신청합니다.
3. 네이버에는 사용하는 두 센터의 공인 IP를 등록합니다.
4. 발급된 Client ID와 Client Secret은 작업할 센터 PC의 PowerShell 환경변수에만 넣습니다.

| 변수 | 용도 |
|---|---|
| `NAVER_COMMERCE_CLIENT_ID` | 커머스 API Client ID |
| `NAVER_COMMERCE_CLIENT_SECRET` | 전자서명용 Client Secret. bcrypt salt 형식 |

비밀키는 화면, 데이터베이스, Git 또는 Vercel 환경변수에 넣지 않습니다. 이미지 변환과 HTML 미리보기는 자격증명 없이 사용할 수 있습니다. 실제 네이버 조회·수정만 센터 PC의 연결 프로그램이 수행합니다.

## 센터 PC 최초 설치

시스템 담당자가 `release/SmartstoreCenterSetup.exe`를 각 센터 PC에 USB, 사내 공유 폴더 또는 메일로 전달합니다. 프로젝트 소스와 Node.js는 필요하지 않습니다.

1. 기존 PowerShell 연결 프로그램이 실행 중이면 `Ctrl+C`로 종료합니다.
2. `SmartstoreCenterSetup.exe`를 더블클릭합니다.
3. Windows가 보호 경고를 표시하면 **추가 정보 → 실행**을 선택합니다. 사내 배포용 무서명 파일이므로 게시자는 알 수 없음으로 표시될 수 있습니다.
4. 새로 발급한 애플리케이션 ID와 시크릿을 입력합니다. 시크릿은 화면에 표시되지 않으며 현재 Windows 사용자 계정으로 암호화되어 저장됩니다.
5. 설치 완료 메시지를 확인합니다.
6. WMS 화면을 새로고침해 **이 PC 연결됨**인지 확인합니다.

설치 후에는 Windows 로그인 시 연결 프로그램이 숨김 상태로 자동 실행됩니다. 작업자는 PowerShell을 사용하지 않고 WMS 화면만 사용합니다. Windows 사용자 계정이 여러 개라면 사용하는 계정마다 한 번씩 설치합니다.

연결되지 않으면 다음 순서로 확인합니다.

1. WMS에서 **연결 다시 확인**을 누릅니다.
2. Windows에 로그아웃한 뒤 다시 로그인합니다.
3. `%LOCALAPPDATA%\ANH_WMS\smartstore-center.log`를 시스템 담당자가 확인합니다.
4. 커머스API센터에 **상품** API 그룹이 추가되어 있는지 확인합니다.
5. 네이버에 등록한 공인 IP와 현재 센터에서 `내 아이피`로 확인한 주소가 같은지 확인합니다.
6. 필요하면 `SmartstoreCenterSetup.exe`를 다시 실행해 프로그램과 자격증명을 갱신합니다.

시크릿이 화면 공유, 캡처 또는 채팅에 노출되면 즉시 재발급합니다.

## 데이터베이스

`supabase/migrations/20261113133000_create_smartstore_detail.sql`을 적용합니다. 테이블은 연결 상태, 작업, 작업 항목, 적용 버전을 저장합니다. 최초 반영 범위는 1개입니다.

이미지는 기존 `product-showcase` 버킷의 `smartstore-detail/original`과 `smartstore-detail/deploy`에 분리 저장합니다. 배포본은 최대 너비 860px JPG이며 EXIF를 제거합니다.

## 적용 순서

1. 관리자로 운영지원팀의 **스마트스토어 상세**(`/operations/smartstore-detail`)에 들어가 **이 PC 연결됨**을 확인합니다. 메뉴와 API는 `manage:smartstore_detail` 권한이 있는 관리자만 사용할 수 있습니다.
2. 테스트 상품 1개의 채널 상품번호와 상세 이미지를 넣고 **목록에 추가**를 누릅니다.
3. **미리보기 생성**을 눌러 PC 860px와 모바일 390px 화면을 확인합니다. 이 단계는 네이버 상품을 수정하지 않습니다.
4. 내용과 대상 상품번호가 맞으면 **승인 후 반영**을 누릅니다. 센터 PC가 네이버 상품 원본을 조회하고 다른 필드는 보존한 채 `detailContent`만 바꿉니다.
5. 작업 이력에서 완료 상태를 확인하고 스마트스토어 모바일에서 테스트 상품의 이미지가 열리는지 확인합니다.
6. 확인 후 반영 범위를 5개로 넓혀 다시 확인합니다.
7. 서로 다른 상품 5개가 반영된 뒤에만 전체 허용으로 바꿀 수 있습니다.

같은 채널 상품번호와 같은 HTML 해시는 버전 테이블에 남아 있으면 다시 반영하지 않습니다. 일부 상품이 실패하면 작업은 부분 실패가 되고, 실패한 항목만 재시도합니다. 변경은 감사 로그 `SMARTSTORE_DETAIL`로 남습니다.

## 롤백

API 반영은 HTML 상세를 덮어쓰므로 SmartEditor ONE 원본 문서를 복구하지 못합니다.

1. 작업 이력에서 해당 상품의 적용 전 HTML을 복사합니다.
2. 판매자센터 상품 편집에서 상세 설명을 수동으로 되돌립니다.
3. 같은 문제가 다른 상품에 번지지 않도록 반영 범위를 다시 1개로 제한합니다.

반영 직후 모바일에서 이미지가 깨지면 추가 상품을 반영하지 않고, 적용 전 HTML과 배포 JPG 주소를 기준으로 원인을 확인합니다.
